# 网络优先级调整

当插入上网设备和网线连接时，指定走哪个设备上网

Windows 本机网页工具：双击 EXE 打开浏览器，读取当前网络接口，拖动排序后保存。越靠上，优先级越高。

## 使用

1. 从本仓库的 **Releases** 下载 `NetworkPriority.exe`（网络优先级）。
2. 双击运行，允许 Windows 管理员权限提示。
3. 拖动网络接口左侧手柄调整顺序，也可以使用右侧箭头。
4. 点击 **保存**，同时应用 IPv4 / IPv6 优先级。

| 按钮 | 作用 |
| --- | --- |
| 保存 | 保存接口顺序，退出程序后仍保留设置 |
| 退出 | 关闭程序，保留已保存的网络设置 |
| 恢复默认并退出 | 恢复 Windows 自动优先级，成功后退出 |
| 重新读取 | 重新读取系统接口和当前设置 |

关闭网页不退出后台程序。可以通过系统托盘的网络图标重新打开页面或退出程序。

## 运行环境

- Windows 10 / Windows 11。
- 使用系统自带的 .NET Framework 4.8 和 Windows PowerShell。
- 单文件 EXE，内置网页和网络图标，不需要安装 Python 或 Node.js。
- 更改网络优先级需要管理员权限。

## 工作方式

程序只在 `127.0.0.1` 的随机端口提供网页，通过每次启动生成的控制令牌验证请求。所有操作在本机完成。

保存时调整接口跃点值，并考虑默认路由原有的成本，不修改 IP、网关或 DNS，不禁用网卡。保存失败时尝试恢复本次修改前的设置。

已建立的连接可能暂时继续使用原接口。更具体的路由，例如 VPN 路由，仍按 Windows 路由规则选择。“当前 IPv4 首选”表示已连接接口中默认路由总跃点值最低的接口。

## 从源码构建

在项目目录运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
```

输出：`dist\网络优先级.exe`。使用 Windows 自带的 C# 编译器，不需要额外下载依赖。

## 验证

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\verify.ps1
```

测试使用合成接口数据和隔离的写入模拟，不修改真实网络配置。覆盖排序、无效或过期接口、部分写入失败回滚、保存及恢复自动优先级。

实际接口读取、网页拖动和退出已在 Windows 上检查。管理员权限下的保存、恢复尚未做实机写入验证。
